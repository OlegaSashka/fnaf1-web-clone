# 🐻 Five Nights at Freddy's — HTML5 / Canvas Retro Clone

[cite_start]Аутентичный, высокооптимизированный веб-клон культовой игры **Five Nights at Freddy's 1**[cite: 1]. [cite_start]Проект написан на чистом JavaScript (ES6+) с использованием объектно-ориентированного подхода (ООП) и модульной архитектуры, без использования тяжелых игровых движков.

[cite_start]Игра полностью адаптирована для запуска прямо в браузере и рендерится через производительный HTML5 Canvas[cite: 1, 47].

---

## 🛠️ Технологический стек & Библиотеки

Проект разработан по принципу **Vanilla-first** с привлечением минимального количества проверенных легковесных библиотек через CDN:
* **Движок рендеринга:** HTML5 Canvas 2D (попиксельный графический вывод, оптимизация отрисовки через листы спрайтов).
* [cite_start]**Основной игровой цикл:** `requestAnimationFrame` для плавной анимации панорамы офиса и эффектов помех[cite: 32].
* [cite_start]**Анимации:** [Anime.js](https://animejs.com/) (для сложных таймлайнов, таких как переход победного экрана 6 AM и движение штор)[cite: 47].
* [cite_start]**Аудио-система:** [Howler.js](https://howlerjs.com/) (многоканальный микшер звуков, позиционирование шагов аниматроников, затухание эмбиента и контроль фонового шума кухни)[cite: 47, 52].

## 🏗️ Архитектура и Модули игры

[cite_start]Кодовая база разделена на независимые слабосвязанные компоненты, что исключает появление «спагетти-кода» и упрощает масштабирование[cite: 5, 49]:

1.  **State Manager (Управление сценами):** Архитектура на базе конечного автомата (FSM). [cite_start]Переключает игровые сцены (`MenuScene`, `NightScene`, `TestScene`) с правильной очисткой памяти и ассетов[cite: 47].
2.  **Time & Power Manager:** Автономный контроллер расхода электроэнергии офиса и хода ночных часов. [cite_start]Динамически рассчитывает нагрузку в зависимости от активных дверей, света и открытого планшета[cite: 9, 67].
3.  [cite_start]**Animatronic AI & Movement Graph:** Движок перемещения врагов на основе весов вероятностей (Movement Opportunities) и графов путей[cite: 10, 11]. [cite_start]Поддерживает симуляцию глухих зон (Кухня на CAM 6)[cite: 52].
4.  **Camera & Behavior System:** Менеджер сети камер слежения. [cite_start]Управляет кастомными состояниями комнат, автоматическим панорамированием объектива, эффектами помех ЭЛТ-телевизора и "морганием" при переключении[cite: 47, 104].
5.  **Dynamic UI Rendering (SVG + Canvas Integration):** Уникальная система интерфейса. Тексты главного меню и HUD генерируются программно на Canvas внутри адаптивной SVG-сетки `foreignObject`. [cite_start]Это гарантирует монолитное векторное масштабирование под любые разрешения экранов без размытия пикселей[cite: 82, 83, 94].

## 🎨 Особые фичи и Улучшения

* [cite_start]**Мультиязычность (Localization Ready):** В кодовую базу встроен централизованный словарь переводов[cite: 98, 99]. [cite_start]Смена языка интерфейса происходит динамически в один клик без перезагрузки сцены[cite: 102].
* **Кастомный графический контент:** Для игры были вручную подготовлены и отредактированы уникальные комбинированные кадры камер для ситуаций, когда в одной зоне одновременно находятся несколько аниматроников (например, Бонни + Чика + Фредди на Главной сцене или в Обеденной зоне).
* [cite_start]**Система редких пасхалок (Rare Events):** Реализован менеджер случайных событий, который при каждом переключении камер рассчитывает шанс на появление галлюцинаций (плачущие дети на стенах, меняющиеся постеры Фредди, секретные взгляды в объектив)[cite: 104].
